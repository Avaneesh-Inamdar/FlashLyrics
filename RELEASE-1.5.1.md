# FlashLyrics 1.5.1

- **More lyrics sources:** added KuGou and BetterLyrics (both free, no API key), as used by popular YouTube Music clients. They appear in Settings > lyrics sources, where you can reorder them. Existing users get them added automatically.
- **App tour:** a short walkthrough opens on first install and after each update: the Listening screen, full player mode, floating lyrics from the notification panel, Search, Library and Settings. Replay it any time from Settings > App tour.
- **Fixed:** after granting notification access or "Display over other apps", Settings kept showing the yellow "Grant" state until the app was restarted. It now updates as soon as you return to the app.
- **Tablets:** on the 3-button navigation bar the ad no longer overlaps the buttons. Tablets now request a larger banner, and full-player mode falls back to the main ad unit when its own has no ad, so ads show there too.
- **Android TV:** the D-pad can now leave the side menu and reach the content, including "Connect music player" and every Settings option. A new on-screen **Pointer** (side menu, or the Menu button) lets you click lyric lines, hold OK to long-press, and push against the screen edge to scroll.
- Build: Android Gradle Plugin 9.0 and R8 optimized resource shrinking, as recommended by Google Play.

Version 1.5.1, build 22.
