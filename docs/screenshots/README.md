# Screenshots

These images match the Google Play store listing (1080 × 1920, 9:16). They were captured from the app running on an Android 15 device with ads turned off and the dark theme, while NCS tracks played through a media session.

| File | Shows |

| `01-synced-lyrics.png` | Listening screen with word-by-word synced lyrics |
| `02-floating-lyrics.png` | Floating lyrics window over a music player |

| `04-playback-controls.png` | Expanded playback controls |
